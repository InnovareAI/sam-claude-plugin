# Sam for Claude

Sam, the AI Sales Manager, inside Claude. The Sam plugin connects your Sam workspace and makes Claude use Sam first for anything about selling or outreach.

## Install

1. In Claude, go to Customize, Plugins, Add, Add marketplace, and enter `InnovareAI/sam-claude-plugin`.
2. Install **Sam** from the marketplace.
3. Start a new chat and sign in to Sam when Claude asks.

New versions arrive automatically. Turn on "Sync automatically" for this marketplace to get them as soon as they are published.

Team and Enterprise owners can add this repo once under Organization settings, Plugins & skills, and set Sam to installed by default for everyone.

See [What's new](plugins/sam/README.md) for the current version.
