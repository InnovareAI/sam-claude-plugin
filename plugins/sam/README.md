# Sam for Claude

Sam, the AI Sales Manager, inside Claude. This plugin connects your Sam workspace and makes Claude use Sam first for anything about selling or outreach.

## What's new in 1.3.1

- **Sam runs the interview.** Sam asks one question at a time: who your buyers are, what problem brings them to you, and what you offer. A thin answer gets one sharper follow-up. Then come triggers and your offer, with short choices where the options are clear.
- **New ICP or new service.** Saying "I want a new ICP for a new service" starts Sam's questions straight away.
- **Claude goes to Sam first.** Claude uses Sam instead of answering itself, even when you don't mention Sam.
- **"How complete is my setup?"** Sam answers with your percentage and the top missing items, then offers to continue the interview where it left off. The percentage is a guide only and never stops you from building or launching a campaign.
- **Copy for a saved ICP.** Name one of your saved ICPs and Sam writes for exactly that ICP, without asking again which audience to use.

## Install

In Claude, go to Customize, Plugins, Add, Add marketplace, enter `InnovareAI/sam-claude-plugin`, then install Sam. New versions arrive automatically. If you uploaded a Sam zip before, remove it first so Claude does not have two. Start a new chat per client.
